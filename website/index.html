How it works

Nothing to set up. Nothing new to learn.

2

It sits on the chat box, or press Ctrl+Shift+E (⌘+Shift+E on Mac). The clearer version replaces your draft.

Add it to Chrome

Prompt Memory is on its way to the Chrome Web Store. Until then, install it in four steps.

One click from the Chrome Web Store. Then open a chat, type, and press Improve.

Add to Chrome, it's free→

  1. Get the files. Open the project on GitHub, choose Code → Download ZIP, and extract it. If a friend sent you an extension ZIP, extract that instead.
  2. Load it. Open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the folder that contains manifest.json.
  3. Open a chat. ChatGPT, Claude, Gemini, Perplexity or Grok. Reload it if it was already open.
  4. Type, then press Improve. It sits on the chat box. Nothing is sent to the chat until you press send.
A good first try

write email to my landlord the kitchen tap is leaking since monday, need fixed this week, keep it polite

Installed, but Improve is missing?

Reload the chat page. Check that Prompt Memory is turned on in Chrome's Extensions page and allowed on that site. Still missing? Email hello.promptmemory@gmail.com with the site's name, but no API keys or private conversations.
