How It Works

From rough thought to a prompt you can actually use

1
✍️

Write your prompt

Type your prompt in ChatGPT, Claude, or any supported AI chat — just as you normally would.

2
🎯

Press Enhance

Click the ⊕ button, or press Ctrl+Shift+E (⌘+Shift+E on Mac) — our AI rewrites your prompt with structure, specificity, and context.

3
🚀

Review, then insert

Compare the rewrite with your original. Edit it, use it, or dismiss it. You stay in control of what the chat receives.

Try it in desktop Chrome

Manual installation for now. Prompt Memory is not yet available through a Chrome Web Store listing.

  1. Get the files. Open the project on GitHub, choose Code → Download ZIP, and extract it. If a friend sent you an extension ZIP, extract that instead.
  2. Load the extension. Open chrome://extensions, enable Developer mode, and select Load unpacked. Choose the extension folder inside the project—or the extracted folder containing manifest.json.
  3. Choose your setup. Open Chrome’s Extensions menu and pin Prompt Memory. Open it, review the data disclosure, then continue with Google. Already have an AI provider key? Choose Use your own API key.
  4. Try one rewrite. Reload an open supported chat tab. Type the sample below without sending it, click ⊕, review the rewrite, and insert it when you are ready. Inserting does not send the message.
A safe first test

Write a friendly email to a fictional teammate, Alex, asking to move our project check-in from Tuesday to Thursday. Keep it under 100 words. Do not invent a reason.

Installed, but the button is missing?

Reload the chat page after installing or updating. Check that Prompt Memory is enabled in Chrome’s Extensions page and allowed on that site. Contact hello.promptmemory@gmail.com if it still does not appear; include the site and error message, but no API keys or private conversations.
