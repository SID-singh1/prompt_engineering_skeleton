How it works

Three steps, and you stay in charge of the last one.

  1. 1

    Type it the way you think it

    Write your draft in the chat box as usual. Typos, half sentences and shorthand are fine.

  2. 2

    Press ⊕

    Click the button at the corner of the page or press Ctrl+Shift+E (⌘+Shift+E on a Mac). The rewrite streams onto a card.

  3. 3

    Read it, then decide

    Replace your draft, try another style, or dismiss it. Nothing reaches the chat until you press send.

Every prompt, one library

Search, tag and tick the prompts you want as context for the next rewrite. Your rewrite History sits one tab over.

  • Signed in, your library and History follow you to every computer

  • Three styles

    Shorter, More detail or Open-ended in one click when the first rewrite is not quite it.

  • Keeps your meaning

    It rewrites the request instead of answering it, and aims to keep your names, numbers, code and language, Hinglish included.

  • Voice input

    Speak a prompt with Alt+Shift+V and check the transcript before it is rewritten.

  • Learns what works

    Rate a rewrite with a thumbs up or down. Prompt tracking stays off unless you turn it on.

Your data

Told up front, sent only when you ask.

Prompt Memory does nothing in the background. It reads your draft when you press ⊕, and the first time it tells you exactly what will be sent.

Read the privacy policy →

  • Signed in

    Your draft and a few recent messages from the open chat go to our server and an AI provider. Drafts and rewrites are kept in your History. Chat context has an off switch.

  • Your own key, no account

    The draft goes straight from your browser to the provider you chose. Your key stays in this browser's storage.

  • Leaving

    Delete your account and everything stored with it from the extension's toolbar menu.

Install

Add it to Chrome in a minute.

  1. Add the extension. Open the Chrome Web Store listing and choose Add to Chrome.
  2. Choose your setup. A tab opens explaining what is sent. Agree, then continue with Google, or choose I have my own API key.
  3. Try one rewrite. Open a supported chat, type the sample below without sending it, and press ⊕.

Try it in desktop Chrome.

The Chrome Web Store listing is on its way. Until then, installing by hand takes about two minutes.

  1. Get the files. Open the project on GitHub, choose Code → Download ZIP, and extract it. If someone sent you an extension ZIP, extract that instead.
  2. Load the extension. Open chrome://extensions, turn on Developer mode, and choose Load unpacked. Pick the extension folder inside the project, or the extracted folder that contains manifest.json.
  3. Choose your setup. Pin Prompt Memory from Chrome's Extensions menu and open it. Read what is sent, then continue with Google, or choose I have my own API key.
  4. Try one rewrite. Reload an open chat tab, type the sample below without sending it, and press ⊕.

A safe first test

Write a friendly email to a fictional teammate, Alex, asking to move our project check-in from Tuesday to Thursday. Keep it under 100 words. Do not invent a reason.

Installed, but the button is missing?

Reload the chat page after installing or updating. Check that Prompt Memory is turned on in Chrome's Extensions page and allowed on that site. Still missing? Email hello.promptmemory@gmail.com with the site and the error message, but no API keys or private conversations.

FAQ

Questions people ask first.

Is Prompt Memory free?

Yes. Sign in with Google for 15 free rewrites a day, with no card needed. If you already have a Groq, Gemini or OpenRouter API key you can use that instead, with or without an account.

Which AI chat sites does it work on?

ChatGPT, Claude, Gemini, Perplexity and Grok, in desktop Chrome.

Does it send my message for me?

No. The rewrite appears on a card beside the chat box. You choose whether to replace your draft with it, and nothing reaches the chat until you press send yourself.

What data does Prompt Memory send?

Nothing is sent until you press ⊕. Signed in, your draft and a few recent messages from the open chat go to our server and an AI provider, and you can turn chat context off. With your own API key and no account, the draft goes straight from your browser to that provider. The privacy policy has the full list.

Do I need an API key?

No. Signing in with Google is enough. An API key is optional, for people who would rather use their own provider account.

How do I delete my data?

Open the extension from the Chrome toolbar, choose Delete account and data, and type DELETE to confirm.
