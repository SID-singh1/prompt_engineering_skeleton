# release history of transformers and tqdm, downloading an 11 MB wheel every
# ~30s, so the Space build hangs for hours instead of erroring:

#   sentence-transformers[onnx] -> optimum-onnx 0.1.0
#   optimum-onnx 0.1.0         requires  transformers >=4.36,<4.58
#
# Those ranges do not intersect. Without the extra this file resolves in ~7s.
#

# same MiniLM weights and produce the same vectors. The ONNX path was only
# faster per call, and llm_service.preload_embedding_model already falls back
# to the torch backend automatically. torch is a dependency either way.
